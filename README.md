# Breezo — Breathe easy. Know your air.
**Problem:** Air pollution and heat/humidity stress are hard to act on without a live, city-level read on current and next-3-day conditions.
**Features:** Live US AQI card with colour-coded status bar, PM2.5/PM10/NO2/O3 cards, 72-hour AQI chart with best/worst hour to go out, rule-based personalised tips (General/Child/Elderly/Asthma/Athlete), climate risk badge, red alert banner above AQI 150, and city search with mock-data fallback.
**Tech:** Vite + React 19 + Tailwind CSS 4 + Recharts + lucide-react, using the key-free Open-Meteo geocoding, air-quality and forecast APIs (no backend, no API keys, no AI calls).
**Run:** `npm install` then `npm run dev`, then open http://localhost:5173
