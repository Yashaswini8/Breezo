# Breezo 🍃
**Breathe easy. Know your air.**

Hackathon Track: **Clean Air & Climate Resilience**

## Problem
Air pollution and heat waves quietly harm millions, yet most people can't easily tell when the air is unsafe or what to do about it.

## Solution
Breezo is a smart air quality dashboard that turns live AQI and weather data into a 72-hour forecast and personalised health advice, all in one simple, easy-to-read view.

## Features
- **Live AQI** for any city, with a colour-coded category and status bar
- **Pollutant breakdown:** PM2.5, PM10, NO2 and O3
- **72-hour AQI forecast** with the best and worst hours to go outside
- **Personalised tips** for General, Child, Elderly, Asthma and Athlete profiles (masks, outdoor exercise, windows, best time outdoors)
- **Climate risk score** (Low / Medium / High) combining AQI, temperature and humidity
- **Red health alert** when AQI goes above 150
- **Clean white, high-contrast design** that works on mobile and desktop

## Tech Stack
- React + Vite
- Tailwind CSS
- Recharts
- lucide-react
- Open-Meteo open data (air quality, weather and geocoding)

## Run Locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173

## Impact
Children, the elderly and people with asthma can act early and stay protected, while communities become more resilient to pollution and climate stress.
